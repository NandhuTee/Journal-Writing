# Research Journal Writing: Words and Patterns to Avoid

> **Daily-review guide:** Each word or pattern has its own row and
> column. These are not universally banned words; scientific accuracy
> and the target journal's rules come first.

## 1. Informal Words — Avoid

| Avoid / Check      | Prefer / Action                            |
|--------------------|--------------------------------------------|
| **a lot**          | many, substantial, or give the exact value |
| **lots of**        | many, numerous, or give the exact value    |
| **get**            | obtain, receive, acquire                   |
| **got**            | obtained, received, acquired               |
| **big**            | large, substantial, considerable           |
| **huge**           | substantial, considerable                  |
| **tiny**           | minimal, small                             |
| **pretty (quite)** | relatively, fairly                         |
| **really**         | remove or use a precise term               |
| **very**           | remove or use a precise adjective          |
| **kind of**        | somewhat, relatively                       |
| **sort of**        | somewhat, relatively                       |
| **okay / OK**      | acceptable, satisfactory                   |
| **stuff**          | materials, factors, components             |
| **thing / things** | factor, aspect, element, component         |
| **good**           | effective, beneficial, appropriate         |
| **bad**            | poor, ineffective, adverse                 |
| **nice**           | appropriate, satisfactory                  |

| Avoid / Check             | Prefer / Action                                 |
|---------------------------|-------------------------------------------------|

## 4. Subjective Words — Avoid Unless Supported

| Avoid / Check      | Prefer / Action                          |
|--------------------|------------------------------------------|
| **amazing**        | report the measured result               |
| **incredible**     | report the measured result               |
| **excellent**      | effective / high, with evidence          |
| **outstanding**    | improved / higher, with a metric         |
| **remarkable**     | notable, if justified                    |
| **fantastic**      | remove and report the result             |
| **wonderful**      | remove and report the result             |
| **perfect**        | use only if demonstrated                 |
| **impressive**     | substantial / measurable                 |
| **superior**       | specify the comparison metric            |
| **dramatic**       | substantial / marked, if supported       |
| **revolutionary**  | novel, if demonstrated                   |
| **groundbreaking** | novel / first reported, only if verified |
| **brilliant**      | remove                                   |
| **terrible**       | poor / adverse, with evidence            |

| **a minority**     | give the percentage/count       |

| **a small number** | give the exact number           |

|----------------|-----------------------------------------------|
| **I**          | use only if permitted by the journal          |
| **me**         | usually restructure                           |
| **my**         | use only if permitted                         |
| **mine**       | usually avoid in scientific prose             |
| **we**         | acceptable in many modern journals            |
| **us**         | acceptable when appropriate                   |
| **our**        | acceptable when appropriate                   |
| **I think**    | avoid; give an evidence-based interpretation  |
| **we think**   | prefer 'the results suggest' when appropriate |
| **I believe**  | avoid; provide evidence                       |
| **we believe** | use cautiously; prefer evidence-based wording |

| Avoid / Check       | Prefer / Action                           |
|---------------------|-------------------------------------------|

| **unfortunately**   | state the limitation objectively          |
| **sadly**           | remove                                    |
| **happily**         | remove                                    |

## 9. Absolute Words — Unless Proven

| Avoid / Check         | Prefer / Action                                    |
|-----------------------|----------------------------------------------------|
| **always**            | generally / under the tested conditions            |
| **never**             | was not observed / has not been reported           |
| **all**               | specify the population/sample                      |
| **every**             | specify the population/sample                      |
| **completely**        | substantially, unless fully demonstrated           |
| **entirely**          | use only when supported                            |
| **absolutely**        | remove or quantify                                 |
| **definitely**        | results indicate / evidence supports               |
| **undoubtedly**       | evidence suggests / results indicate               |
| **certainly**         | use only when justified                            |
| **impossible**        | unlikely / not feasible under specified conditions |
| **guaranteed**        | expected / associated with, as appropriate         |
| **proven**            | demonstrated / supported by evidence               |
| **unquestionably**    | remove or provide evidence                         |
| **without exception** | use only when demonstrated                         |
| **100% effective**    | use only if the data establish this                |

| **perhaps**     | usually use more evidence-based wording          |
| **probably**    | quantify probability when possible               |
| **likely**      | use when evidence supports likelihood            |
| **possibly**    | use when uncertainty is genuine                  |
| **apparently**  | avoid when direct observation is available       |
| **seemingly**   | avoid when clearer wording is possible           |
| **appears to**  | acceptable for indirect evidence                 |
| **seems to**    | prefer a more specific statement                 |
| **suggests**    | useful for cautious interpretation               |
| **potentially** | use only for a genuine potential                 |
| **presumably**  | explain the assumption instead                   |

## 15. Common Grammar Patterns to Avoid

| Pattern to Check                  | Correct Practice                                      |
|-----------------------------------|-------------------------------------------------------|
| **Dangling modifiers**            | connect the modifier to the correct subject           |
| **Sentence fragments**            | write a complete sentence                             |
| **Run-on sentences**              | separate independent ideas correctly                  |
| **Double negatives**              | use one clear negative construction                   |
| **Slang**                         | use formal scientific language                        |
| **Colloquialisms**                | use precise academic wording                          |
| **Idioms**                        | use literal, internationally clear wording            |
| **Rhetorical questions**          | usually convert to direct statements                  |
| **Exclamation marks (!)**         | normally avoid in scientific prose                    |
| **Excessive passive voice**       | use active voice when clearer                         |
| **Unclear pronouns**              | identify the exact noun                               |
| **Ambiguous comparisons**         | state exactly what is compared                        |
| **Unsupported causal language**   | do not claim causation from association alone         |
| **Excessive nominalization**      | use a clear verb when possible                        |
| **Excessively long sentences**    | divide into logical sentences                         |
| **Subject–verb disagreement**     | match the subject and verb                            |
| **Inconsistent tense**            | choose tense according to purpose                     |
| **Incorrect articles**            | check a, an, and the                                  |
| **Repeated sentence openings**    | vary structure naturally                              |
| **Unnecessary direct quotations** | paraphrase and cite when exact wording is unnecessary |

### Grammar Examples

| Avoid                                                                | Prefer                                                                      |
|----------------------------------------------------------------------|-----------------------------------------------------------------------------|
| **After analyzing the data, significant differences were observed.** | After analyzing the data, the researchers observed significant differences. |
| **Using the proposed method, accuracy was improved.**                | Using the proposed method, the researchers improved the accuracy.           |

## 16. Anti-Pattern List — Always Check and Fix

| Anti-Pattern                           | Action                                              |
|----------------------------------------|-----------------------------------------------------|
| **Unsupported claims**                 | add evidence/citation or revise                     |
| **Promotional language**               | use measurable, objective language                  |
| **Emotional language**                 | report objectively                                  |
| **Vague quantities**                   | provide numbers, percentages, ranges, or categories |
| **Unnecessary filler**                 | remove                                              |
| **Redundant wording**                  | remove repeated meaning                             |
| **Repeated ideas**                     | keep the clearest version                           |
| **Repeated transition words**          | remove or vary naturally                            |
| **Unnecessary jargon**                 | use simpler precise terminology                     |
| **Undefined abbreviations**            | define at first use                                 |
| **Unnecessary contractions**           | use the full form                                   |
| **Slang**                              | replace with formal language                        |
| **Conversational expressions**         | replace with academic wording                       |
| **Unsupported absolute statements**    | qualify according to evidence                       |
| **Excessive hedging**                  | keep only justified uncertainty                     |
| **Dangling modifiers**                 | attach to the correct subject                       |
| **Long overloaded sentences**          | divide into clear sentences                         |
| **Direct quotations without need**     | paraphrase and cite                                 |
| **Citation without explanation**       | explain relevance                                   |
| **Result mixed with personal opinion** | separate observation and interpretation             |
| **Causal claim from correlation**      | use accurate association language                   |
| **Repetitive formulaic wording**       | rewrite based on actual meaning/evidence            |
| **Repeated 'significantly'**           | use only with clear statistical/contextual meaning  |
| **Unclear this / it / they**           | state the exact noun                                |
| **Repeated study aim**                 | state it in the appropriate location                |
| **Claim without citation**             | cite previous research                              |
| **Overgeneralization**                 | restrict to studied population/conditions           |
| **Unexplained acronym**                | define at first use                                 |
| **Inconsistent terminology**           | use technical terms consistently                    |
| **Excessive passive voice**            | use active voice where clearer                      |
| **Excessive first-person wording**     | follow journal style                                |
| **Direct speech in scientific prose**  | normally use indirect reporting                     |

## Quick Memory Formula

| Goal               | Rule                                                 |
|--------------------|------------------------------------------------------|
| **Formal**         | Avoid slang and unnecessary conversational language. |
| **Precise**        | Use exact values and specific terminology.           |
| **Objective**      | Avoid emotional and promotional claims.              |
| **Evidence-based** | Support claims with data or citations.               |
| **Concise**        | Remove filler and redundancy.                        |

> **Formal + Precise + Objective + Evidence-based + Concise + Clear =
> Strong Journal Writing**
