## 📝 Daily Writing Rule

> **Formal + Precise + Objective + Evidence-based + Concise + Clear = Strong Journal Writing**

---

## 🎯 Purpose of This Repository

The purpose of this repository is to maintain a structured collection of journal-writing rules that can be reviewed regularly while preparing research papers.

The notes focus on writing sentences that are:

- Clear
- Grammatically correct
- Academically appropriate
- Evidence-based
- Concise
- Natural
- Suitable for research publications

---

## 📌 Important Note

These notes provide general academic-writing guidance. Requirements may vary between journals.

Always check the **author guidelines of the target journal** before preparing the final manuscript.
