# Academic Writing – Daily Review

## Essential Academic Writing Rules

| Rule                    | Important Point                                        | Journal-Style Example                                      |
| ----------------------- | ------------------------------------------------------ | ---------------------------------------------------------- |
| **Clear Subject**       | Clearly identify what performs the action.             | Fast charging accelerates battery degradation.             |
| **Precise Verb**        | Use a strong and specific academic verb.               | Climate change reshapes renewable-energy risks.            |
| **One Main Idea**       | Present one central message per sentence.              | Solar intermittency affects power-system reliability.      |
| **Conciseness**         | Remove unnecessary words and repetition.               | Thermal management improves charging safety.               |
| **Academic Vocabulary** | Prefer precise and formal terminology.                 | Surface coatings enhance cathode stability.                |
| **Active Voice**        | Use when the actor or action should be clear.          | The researchers compared ten classification models.        |
| **Passive Voice**       | Use when the procedure or object is the focus.         | The cells were charged at different rates.                 |
| **Present Tense**       | Use for established facts and current interpretations. | Renewable sources introduce forecasting uncertainty.       |
| **Past Tense**          | Use for completed experiments and procedures.          | The authors evaluated several charging rates.              |
| **Result Statement**    | State the important finding directly.                  | Gradient boosting achieved 84.5% accuracy.                 |
| **Cause → Effect**      | Clearly express relationships between variables.       | Rapid charging increases thermal stress.                   |
| **Topic Sentence**      | Introduce the paragraph's central idea.                | Solid-state batteries offer advantages for energy storage. |
| **Supporting Sentence** | Provide evidence related to the topic sentence.        | Solid electrolytes can improve thermal stability.          |
| **Conclusion Sentence** | End with the main implication or finding.              | These advances may enable safer energy-storage systems.    |
| **Cohesion**            | Connect sentences in a logical sequence.               | Problem → Method → Result → Implication                    |

---

## ⭐ Daily Review Formula

> **Clear Subject → Precise Verb → One Idea → Concise Wording → Correct Tense → Logical Flow**

### Quick Checklist

Before finalizing an academic sentence, check:

* [ ] Is the **subject** clear?
* [ ] Is the **verb precise**?
* [ ] Does the sentence communicate **one main idea**?
* [ ] Can unnecessary words be removed?
* [ ] Is the **tense appropriate**?
* [ ] Does the sentence connect logically with the previous and next sentences?
