# Academic Modal Verbs Guide for Journal Writing

## Purpose

Modal verbs help express certainty, possibility, obligation, and recommendations. In academic writing, they should be selected carefully to avoid overstating or understating research findings.

---

# Modal Verb Reference

| Modal Verb | Meaning                         | When to Use                                                         | Avoid When                                      | Example                                                                       |
| ---------- | ------------------------------- | ------------------------------------------------------------------- | ----------------------------------------------- | ----------------------------------------------------------------------------- |
| **may**    | Possibility                     | Discussing potential benefits, implications, or future applications | Reporting confirmed experimental results        | The proposed framework **may** support clinical decision-making.              |
| **can**    | Capability                      | Describing what a method or system is capable of doing              | Claiming verified improvements from experiments | CLAHE **can** improve image contrast.                                         |
| **could**  | Possibility or future extension | Discussing future work or possible improvements                     | Describing completed work                       | Additional data **could** improve segmentation performance.                   |
| **should** | Recommendation or expectation   | Providing recommendations or expected outcomes                      | Describing experimental findings                | Future studies **should** include larger datasets.                            |
| **must**   | Strong requirement              | Mathematical facts, standards, or mandatory requirements            | General research claims                         | Input images **must** be resized before training.                             |
| **would**  | Hypothetical situation          | Discussing expected outcomes or hypothetical scenarios              | Reporting actual observations                   | A larger dataset **would** improve model robustness.                          |
| **might**  | Weak possibility                | Discussing uncertain observations                                   | Strong conclusions                              | The performance **might** be influenced by class imbalance.                   |
| **will**   | Future action or certainty      | Research objectives, proposed methodology, or future work           | Discussion of completed experiments             | The proposed framework **will** integrate image enhancement and segmentation. |

---

# Which Modal Verb Should I Use?

| Writing Section     | Recommended Modal Verbs               |
| ------------------- | ------------------------------------- |
| Introduction        | can, may                              |
| Problem Statement   | will, can, should                     |
| Research Objectives | will                                  |
| Methodology         | will (proposal), was (completed work) |
| Results             | No modal verbs; use past tense        |
| Discussion          | may, can, could                       |
| Conclusion          | may, can                              |
| Future Work         | could, should, may                    |

---

# When to Use "May"

Use **may** when discussing potential applications or implications.

✔ Correct

* The proposed framework **may** improve lesion visualization.
* The proposed method **may** assist clinicians.
* The framework **may** facilitate treatment planning.

✘ Avoid

* The framework **may** achieved 95% accuracy.
* The model **may** improved segmentation.

---

# When to Use "Can"

Use **can** to describe capability.

✔ Correct

* CLAHE **can** enhance image contrast.
* Deep learning **can** automate lesion segmentation.

✘ Avoid

* The proposed method **can** achieve 95% accuracy. *(Use "achieved" if verified.)*

---

# When to Use "Could"

Use **could** for future improvements or possibilities.

✔ Correct

* Additional annotated images **could** improve model performance.
* Transformer models **could** be investigated in future work.

---

# When to Use "Should"

Use **should** only for recommendations.

✔ Correct

* Future studies **should** include multicenter datasets.
* The dataset **should** be balanced before training.

✘ Avoid

* The model **should** improve accuracy. *(Unless making a recommendation.)*

---

# When to Use "Will"

Use **will** in proposals, objectives, and problem statements.

✔ Correct

* This study **will** develop an integrated framework.
* The proposed pipeline **will** improve lesion visualization.

✘ Avoid

* The proposed method **will** achieve superior performance. *(Unless this is a stated objective rather than a result.)*

---

# When Not to Use Modal Verbs

Avoid modal verbs when reporting completed experimental findings.

✔ Correct

* The proposed framework **achieved** a Dice score of 0.87.
* CLAHE **improved** image contrast by 24.2%.
* The model **demonstrated** high segmentation accuracy.

✘ Avoid

* The framework **may improve** the Dice score to 0.87.
* CLAHE **can increase** contrast by 24.2%.
* The model **could achieve** high accuracy.

---

# Recommended Usage by Sentence Type

| Sentence Type                     | Recommended Verb                 |
| --------------------------------- | -------------------------------- |
| Reporting results                 | achieved, improved, demonstrated |
| Describing capability             | can                              |
| Discussing implications           | may                              |
| Making recommendations            | should                           |
| Stating future work               | could                            |
| Writing research objectives       | will                             |
| Expressing mandatory requirements | must                             |

# Quick Decision Guide

| If you want to...              | Use           |
| ------------------------------ | ------------- |
| Report an experimental result  | No modal verb |
| Describe a model's capability  | can           |
| State a possible benefit       | may           |
| Recommend future work          | should        |
| Suggest a possible improvement | could         |
| Describe proposed work         | will          |
| State a mandatory requirement  | must          |

# Examples

| Weak                                                                  | Better                                     |
| --------------------------------------------------------------------- | ------------------------------------------ |
| The framework may improve Dice score.                                 | The framework improved the Dice score.     |
| The model can achieve 95% accuracy.                                   | The model achieved 95% accuracy.           |

# Section-wise Use of Modal Verbs in Academic Journal Writing

## Abstract

### Use

* Report the completed study using the **past tense**.
* State the main conclusion using the **present tense**.
* Use **may** only when discussing possible applications or implications.

### Avoid

* **will**, **should**, and **could** when describing completed work.
* Overstating conclusions without evidence.

### Examples

✔ This study **proposed** a deep learning framework.

✔ The proposed method **achieved** a Dice score of 0.87.

✔ The framework **may** assist clinicians in lesion assessment.

✘ This study **will propose** a framework.

✘ The framework **can achieve** a Dice score of 0.87.

---

# Introduction

### Use

* Present accepted scientific facts in the **present tense**.
* Use **can** to describe general capabilities.
* Use **may** when discussing potential benefits reported in the literature.

### Avoid

* Future tense unless introducing the study objectives.
* Strong clinical claims without evidence.

### Examples

✔ Deep learning **can** improve medical image analysis.

✔ CNNs **have demonstrated** high performance in image segmentation.

✔ Automated analysis **may** improve diagnostic consistency.

---

# Problem Statement

### Use

* Describe the current problem in the **present tense**.
* Use **will** to describe what the proposed research intends to accomplish.
* Use **can** when describing expected system capabilities.

### Avoid

* Past tense for current research gaps.
* Claiming completed results.

### Examples

✔ Existing methods **are limited** to binary classification.

✔ The proposed framework **will integrate** image enhancement and segmentation.

✔ The framework **can** improve lesion visualization.

✘ The proposed framework **improved** segmentation accuracy.

---

# Literature Review

### Use

* Report previous studies in the **past tense**.
* Use reporting verbs such as **proposed**, **developed**, **evaluated**, and **demonstrated**.

### Avoid

* Future tense.
* Claiming previous work as ongoing.

### Examples

✔ Smith et al. **proposed** a U-Net architecture.

✔ They **evaluated** VGG19 on laparoscopic images.

✔ The authors **demployed** transfer learning.

---

# Methodology

### Proposal

Use **will** because the work has not yet been conducted.

✔ CLAHE **will be applied**.

✔ Images **will be enhanced** before segmentation.

✔ DnCNN **will reduce** image noise.

### Completed Study

Use the **past tense** only.

✔ CLAHE **was applied**.

✔ Images **were enhanced**.

✔ Data augmentation **was performed**.

### Avoid

* **may**
* **can**
* **could**

because the methodology should describe exactly what was done.

---

# Results

### Use

* Report only observed findings.
* Use reporting verbs such as:

  * achieved
  * improved
  * demonstrated
  * increased
  * reduced
  * outperformed
  * yielded

### Avoid

* **may**
* **can**
* **could**
* **should**
* **will**

because the results section should report facts supported by experimental evidence.

### Examples

✔ The proposed model **achieved** a Dice score of 0.87.

✔ CLAHE **improved** image contrast by 24.2%.

✔ The framework **demonstrated** superior segmentation performance.

✘ The framework **may improve** segmentation accuracy.

✘ The framework **can achieve** high Dice scores.

---

# Discussion

### Use

* Explain why the results occurred.
* Interpret findings.
* Discuss limitations.
* Compare with previous studies.

Use

* **may**
* **can**
* **could**
* **might**

because these statements are interpretations rather than directly observed facts.

### Examples

✔ The improvement **may** result from enhanced image contrast.

✔ Class imbalance **could** affect minority-class performance.

✔ CLAHE **can** improve lesion visibility.

---

# Conclusion

### Use

* Summarize the main findings.
* Discuss broader implications.
* Mention potential clinical applications cautiously.

Use

* **may**
* **can**
* **has the potential to**

### Avoid

* Strong clinical claims that were not validated.

### Examples

✔ The proposed framework **may** support clinicians.

✔ The framework **can** facilitate lesion analysis.

✔ The proposed method **has the potential to** improve computer-assisted diagnosis.

✘ The framework **will** improve clinical diagnosis.

✘ The framework **guarantees** accurate diagnosis.

---

# Future Work

### Use

Discuss planned extensions and recommendations.

Use

* **could**
* **should**
* **will**
* **may**

### Examples

✔ Future studies **could** investigate transformer-based architectures.

✔ Larger multicenter datasets **should** be collected.

✔ The framework **will** be extended to real-time surgical applications.

✔ Additional annotations **may** improve minority-class segmentation.

---

# Clinical Implications

Always use cautious language unless your study includes clinical validation.

### Preferred

✔ may support clinicians

✔ may facilitate clinical decision-making

✔ has the potential to improve diagnosis

✔ can assist treatment planning

✔ may contribute to improved patient care

### Avoid

✘ replaces clinicians

✘ guarantees diagnosis

✘ ensures treatment success

✘ eliminates diagnostic errors

✘ proves clinical effectiveness

# Quick Decision Table

| If you are writing... | Use                              | Avoid                             |
| --------------------- | -------------------------------- | --------------------------------- |
| Established facts     | Present tense                    | Future tense                      |
| Previous studies      | Past tense                       | Future tense                      |
| Research objectives   | will                             | Past tense                        |
| Methods (proposal)    | will                             | may, could                        |
| Methods (completed)   | Past tense                       | will                              |
| Results               | achieved, improved, demonstrated | may, can, could                   |
| Discussion            | may, can, could                  | Strong certainty without evidence |
| Conclusion            | may, can, has the potential to   | guarantees, proves                |
| Future work           | could, should, will              | Past tense                        |
