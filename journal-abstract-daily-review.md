## Abstract Writing -- Daily Rules

  -----------------------------------------------------------------------
  Rule                                Remember
  ----------------------------------- -----------------------------------
  **Length**                          Follow the **target journal's word
                                      limit**

  **Content**                         Problem → Method → Key Results →
                                      Conclusion / Significance

  **Writing Style**                   **Clear, concise, precise**

  **Background**                      Keep only what is necessary

  **Results**                         Include the **most important
                                      findings**

  **Audience**                        Write from the **reader / reviewer
                                      perspective**

  **Final Check**                     Always follow the **specific
                                      journal guidelines**

  **Best Time to Write**              Write the **abstract after
                                      completing the main paper**
  -----------------------------------------------------------------------
