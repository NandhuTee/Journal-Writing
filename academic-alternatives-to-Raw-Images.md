# Academic Alternatives to "Raw Images"

Formal academic alternatives to **"raw images"** for IEEE and biomedical journal writing.

| Original | Academic alternative | Best use |
|---|---|---|
| Raw images | **Original images** ✅ | General; safest alternative |
| Raw images | **Unprocessed images** | Images before preprocessing |
| Raw images | **Unprocessed image data** | Biomedical/computational studies |
| Raw images | **Original image data** | General scientific writing |
| Raw images | **Acquired images** | Images obtained directly from an imaging system |
| Raw images | **Source images** | Images used as the initial input |
| Raw images | **Input images** | Machine learning/deep learning |
| Raw images | **Native images** | Images in their original acquisition format |
| Raw images | **Pre-acquisition images** | When emphasizing acquisition stage |
| Raw images | **Preprocessed-free images** | ❌ Avoid; grammatically awkward |
| Raw images | **Unaltered images** | Images that have not been modified |
| Raw images | **Original image acquisitions** | Imaging/clinical studies |
| Raw images | **Initial image data** | Computational analysis |
| Raw images | **Primary image data** | Dataset or analysis context |
| Raw images | **Source image data** | Image-processing pipelines |

## Examples

Instead of:

> **Raw images were collected from the imaging database.**

Use:

> **Original images were collected from the imaging database.** ✅

Or:

> **Unprocessed images were obtained from the imaging database.** ✅

## Context-Specific Examples

| Avoid | Prefer |
|---|---|
| Raw images were used for analysis. | **Unprocessed images were used for analysis.** |
| Raw images were collected from the patients. | **Original images were acquired from the patients.** |
| Raw images were preprocessed before classification. | **The acquired images were preprocessed before classification.** |
| The raw images were resized to 224 × 224 pixels. | **The original images were resized to 224 × 224 pixels.** |
| Raw images were converted to grayscale. | **The acquired images were converted to grayscale.** |
| The model was trained using raw images. | **The model was trained using unprocessed images.** |
| Raw images were used as input to the CNN. | **The acquired images were used as input to the CNN.** |
| Raw images were subjected to noise removal. | **The unprocessed images underwent noise reduction.** |
| Raw images were enhanced using histogram equalization. | **The original images were enhanced using histogram equalization.** |
| Raw images were obtained from the imaging device. | **Images were directly acquired from the imaging device.** |

## Recommended Usage

### 1. "Unprocessed images" — Most recommended for preprocessing studies

Use this term when the images have **not undergone preprocessing, enhancement, normalization, segmentation, or other transformations**.

> **The unprocessed images were subjected to intensity normalization before model training.**

### 2. "Original images" — Best general alternative

Use this when referring to the images in their **initial/original form** without emphasizing a specific processing stage.

> **The original images were divided into training, validation, and test sets.**

### 3. "Acquired images" — Best for imaging studies

Use this when emphasizing that images were **obtained from an imaging device, modality, or clinical imaging system**.

> **The acquired images were transferred to the workstation for subsequent analysis.**

### 4. "Input images" — Best for AI/ML studies

Use this when the images serve as the **input to a computational model**.

> **The input images were normalized before being provided to the convolutional neural network.**

### 5. "Source images" — Best for image-processing workflows

Use this when the images represent the **starting point of an image-processing pipeline**.

> **The source images were subjected to preprocessing and augmentation before classification.**

## Terms to Avoid or Use Carefully

| Term | Recommendation | Reason |
|---|---|---|
| Raw images | ⚠️ Use carefully | Common but somewhat informal/ambiguous |
| Raw image | ⚠️ Use carefully | May not clearly indicate the processing state |
| Raw image data | ⚠️ Use carefully | Acceptable but can be ambiguous |
| Raw pictures | ❌ Avoid | Too informal for scientific writing |
| Unprocessed pictures | ❌ Avoid | "Images" is more appropriate |
| Preprocessed-free images | ❌ Avoid | Grammatically unnatural |
| Untreated images | ⚠️ Avoid in most imaging contexts | "Untreated" is more appropriate for biological samples |
| Original images | ✅ Recommended | Clear and formal |
| Unprocessed images | ✅ Recommended | Precise for preprocessing studies |
| Acquired images | ✅ Recommended | Appropriate for imaging acquisition |
| Input images | ✅ Recommended | Appropriate for computational/AI studies |
| Source images | ✅ Recommended | Appropriate for image-processing workflows |

## Quick Replacement Guide

| If you mean... | Use... |
|---|---|
| Images in their original form | **Original images** |
| Images before preprocessing | **Unprocessed images** |
| Images obtained from an imaging device | **Acquired images** |
| Images provided to a model | **Input images** |
| Starting images in a processing pipeline | **Source images** |
| Images that have not been modified | **Unaltered images** |
| Original dataset | **Original image data** |

## Preferred Academic Choices

**Most generally recommended:**

> **Original images**

**When referring specifically to preprocessing:**

> **Unprocessed images**

**When referring to image acquisition:**

> **Acquired images**

**When referring to AI/ML model input:**

> **Input images**

**When referring to an image-processing pipeline:**

> **Source images**

> **Note:** Choose the term according to the exact meaning. In biomedical and IEEE writing, **"unprocessed images"** is usually more precise than **"raw images"** when the intended meaning is that no preprocessing has been performed.
